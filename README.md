# Mirro (робоча назва «Мій двійник»)

Персонаж, який змінюється разом із людиною: їжа, рух і зважування. Версія 1.0 працює повністю на телефоні:
без акаунта, без сервера, без ШІ.

> Приватний код. Усі права захищені — див. [LICENSE](LICENSE).

## Структура

| Шлях | Що це |
| --- | --- |
| `src/index.html`, `src/app.css`, `src/app.js` | Застосунок (той самий код, що й у веб-версії в Claude) |
| `src/config.js` | Перемикачі функцій. `features.ai: false` у версії 1.0 |
| `src/storage.js` | Надійне збереження: дубль даних у файл на телефоні / IndexedDB у браузері; збереження файлів через «Поділитися»; кнопка «Назад» на Android |
| `src/sw.js`, `src/manifest.webmanifest` | Встановлювана веб-версія (PWA), працює офлайн |
| `scripts/build.mjs` | Збирання `src/` → `www/` (мініфікація, локальні шрифти, кеш офлайн) |
| `android/`, `ios/` | Нативні проєкти Capacitor |
| `tests/smoke.mjs` | Автотест основних сценаріїв, включно з «їжа не пропадає» |
| `docs/` | Чекліст запуску, випуск оновлень, політика конфіденційності |

## Команди

```bash
npm ci                    # залежності
npm run build             # src/ → www/
npm run serve             # відкрити www/ на http://localhost:8080
npm test                  # збирання + автотест (потрібен Playwright)
npm run build:artifact    # dist/claude-artifact.html — версія з ШІ для тесту в Claude
npm run android           # збирання + копіювання в android/, далі: npx cap open android
npm run ios               # те саме для iOS (потрібен Mac з Xcode)
```

`npm run build:artifact` збирає один HTML-файл із увімкненим ШІ. Його можна опублікувати в Claude для
тестувальників (етап 1 плану).

## Дані

- Усі дані — в одному обʼєкті `D` (ключ `dvijnyk.v1`). Кожне збереження ставить `savedAt` і дублюється у файл
  (телефон) або IndexedDB (браузер); при запуску перемагає новіша копія.
- `D.v` — версія структури даних. Зміна структури = новий крок у `migrate()` в `src/app.js`, щоб старі записи
  перетворилися без втрат (див. [docs/RELEASE.md](docs/RELEASE.md)).
- Кожен запис їжі, активності й замірів має `uid` — це основа для обʼєднання записів із двох телефонів у
  версії 1.2.

## Збирання Android

Кожен push запускає GitHub Actions (`.github/workflows/build.yml`): автотест → debug APK (артефакт
`app-debug-apk`). Підписаний AAB для Google Play збирається, коли в налаштуваннях репозиторію задано секрети
ключа завантаження — див. [docs/RELEASE.md](docs/RELEASE.md).

ID застосунку зараз тимчасовий: `com.example.dvijnyk`. Google Play його не прийме — замінити до першого
завантаження (див. чекліст).
